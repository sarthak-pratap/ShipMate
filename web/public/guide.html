The problem

Config is the tax

Your code works. Then you spend an afternoon hand-writing YAML — service names, ports, dependencies, secrets — just to get it live. ShipMate removes that step and shows its work (a diagram, a linter, and plain-English notes) so you can trust what it generated.

How it works

Five steps to live

1 · Give it your app

Pick an input mode and paste a compose file, a public GitHub URL, or a description. Optionally tick ✨ use AI to fill gaps.

2 · Generate

Get a topology diagram, a 0–10 deploy-readiness score, the zerops.yaml, the project-import file, and notes explaining every inference.

3 · Review the lint

The linter flags the mistakes that break first deploys — each with a one-line fix. Aim for a green ship it.

4 · Deploy wizard

Answer a few questions (project name, new vs existing, which services, DB HA) and download deploy.sh.

5 · Ship it

Run bash deploy.sh from your repo root, set any flagged secrets in the Zerops GUI, and you're live.

Input modes

Three ways in

🐳 docker-compose

Paste a compose file. Fully deterministic — services, images, ports and depends_on map straight to Zerops.

🐙 repo URL

Paste a public GitHub repo. Detects the stack, monorepos, and Dockerfiles. No clone, no setup.

💬 prompt

Describe the app in plain English. Uses an LLM when configured, a keyword parser when not — always works.

Deploy

One command, not a paste

The wizard builds a real shell script for your exact situation. Download it and run:

# from the root of your app's repo, with zcli logged in
bash deploy.sh
Don't paste the script line-by-line — the heredocs and zcli prompts break on partial pastes. Download deploy.sh and run it.

Good to know

FAQ

Do I need to install anything to try it?

No — the app runs in your browser. You only need zcli when you actually deploy.

Does it need an API key?

No. Prompt mode and AI gap-fill use one if present, but everything has an offline fallback.

Private repos?

Not yet — public GitHub repos only.

Is the generated config guaranteed perfect?

It's a strong, review-then-ship starting point — validated against the Zerops docs and real deploys. Read the notes and the lint tab first.
